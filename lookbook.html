Reform Council Tracker · Design directions

One tracker, three looks

Activists can switch the tracker between three styles, each designed to feel familiar to a different audience. The facts, stories and links stay the same in every look. Only the presentation changes, using a slider in the site footer.

Same facts, every lookHeadlines, figures and sources are identical. Only the tagline and styling change.
Neutral names in publicThe slider shows Bold, Refined and Civic. The labels describe the style, not the audience.
Evoke, don't imitateNo retailer, party or brand logos, typefaces or colours. Each look borrows a feel, never an identity.

The footer switcher

A three-stop slider in the footer. Moving it cross-fades the whole site into the new look and adds it to the page link, so a shared link opens in the same style. Try it below.

This works in the browser as it will on the site. Colours ease across and the page cross-fades, with an instant switch where cross-fading isn't supported. Shared links would carry the look, for example …/story.html?id=…&look=refined.

Next steps

  1. Restructure the styling into themes. Move the site's colours, fonts and shapes into named settings, as on this page. The public site won't look any different yet.
  2. Add the footer slider and look-in-the-link. A ?look= setting in the link keeps shared links in the chosen style. The viewer's last choice is remembered.
  3. Build Refined, then Civic. Beyond colours and fonts, each needs its own opening screen and card styles. Map colours come from the theme.
  4. Taglines per look. This is the only wording that changes. Everything else stays the same.
  5. Test with real audiences. Show each look to a few people from its target group before launch.
